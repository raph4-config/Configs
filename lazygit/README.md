# lazygit

`config.yml`, copied to `~/Library/Application Support/lazygit/` by `sync-config`.

| Key         | Does                                          |
| ----------- | --------------------------------------------- |
| `lg`        | open lazygit                                  |
| `␣ g g`     | open lazygit from Neovim                      |
| `C` (files) | gitmoji commit: pick a type, type the message |
