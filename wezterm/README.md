# wezterm

`.wezterm.lua`, copied to `~/.wezterm.lua` by `sync-config`. Tokyo Night, JetBrainsMono NF 14,
fullscreen at launch.

| Key             | Does                               |
| --------------- | ---------------------------------- |
| `⌘ D` / `⌘ ⇧ D` | split left \| right / top / bottom |
| `⌘ h j k l`     | move between panes                 |
| `⌘ W` / `⌃ D`   | close pane                         |
| `⌘ T` / `⌘ N`   | new tab / window                   |
| `⌘ 1..9`        | go to tab                          |
| `⌘ ⇧ [` / `]`   | previous / next tab                |
| `⌥ Enter`       | toggle fullscreen                  |
| `⌘ F`           | search scrollback                  |
| `⌃ ⇧ X`         | copy mode                          |
| `⌃ ⇧ P`         | command palette                    |
