# macOS

`⌘` Cmd · `⌥` Option · `⌃` Ctrl · `⇧` Shift

## Text navigation (kill the arrow-spam)
| Move | Key |
|------|-----|
| Word left / right | `⌥ + ← / →` |
| Line start / end | `⌘ + ← / →` |
| Doc top / bottom | `⌘ + ↑ / ↓` |
| Delete word back | `⌥ + ⌫` |
| Delete to line start | `⌘ + ⌫` |
| Select | add `⇧` to any move above |

## Windows & apps
| Action | Key |
|--------|-----|
| Switch app | `⌘ + Tab` |
| Switch windows of app | `⌘ + ` (backtick) |
| Spotlight (launch/search) | `⌘ + Space` |
| Hide app / Minimize | `⌘ + H` / `⌘ + M` |
| Close window / Quit app | `⌘ + W` / `⌘ + Q` |
| Fullscreen | `⌃ + ⌘ + F` |

## AeroSpace (tiling)
Modificateur : `⌥` alt. Focus en `hjkl` (les `⌥ + ←/→` restent la navigation texte macOS).

| Action | Key |
|--------|-----|
| Focus fenêtre | `⌥ + H / J / K / L` |
| Déplacer la fenêtre | `⌥ + ⇧ + H / J / K / L` |
| Workspace 1..9 | `⌥ + 1..9` |
| Envoyer la fenêtre au workspace | `⌥ + ⇧ + 1..9` |
| Workspace précédent | `⌥ + Tab` |
| Workspace vers l'autre écran | `⌥ + ⇧ + Tab` |
| Redimensionner | `⌥ + - / =` |
| Équilibrer les tailles | `⌥ + ⇧ + =` |
| Fullscreen | `⌥ + F` |
| Layout tiles h/v | `⌥ + /` |
| Layout accordion h/v | `⌥ + ,` |
| Flottant <-> tuilé | `⌥ + ⇧ + Espace` |
| Ouvrir / focus WezTerm | `⌥ + Entrée` |
| Grouper avec la voisine | `⌥ + ⇧ + Entrée` puis `h/j/k/l` |
| Mode service | `⌥ + ⇧ + ;` |

Mode service : `esc` recharge la config, `r` remet l'arbre à plat, `f` bascule flottant,
`⌫` ferme toutes les autres fenêtres.

## Spaces / Mission Control
| Action | Key |
|--------|-----|
| Mission Control | `⌃ + ↑` |
| Switch desktop | `⌃ + ← / →` |
| App windows (Exposé) | `⌃ + ↓` |

## Screenshots
| Action | Key |
|--------|-----|
| Selection to file | `⌘ + ⇧ + 4` |
| Capture menu (record, options) | `⌘ + ⇧ + 5` |
| Selection to clipboard | add `⌃` |

## Finder
| Action | Key |
|--------|-----|
| Go to folder | `⌘ + ⇧ + G` |
| Up / Open | `⌘ + ↑` / `⌘ + ↓` |
| New folder | `⌘ + ⇧ + N` |
