# shortcuts

macOS and Chrome, no config here.

## macOS

| Key                   | Does                                        |
| --------------------- | ------------------------------------------- |
| `⌘ ⇥` / `` ⌘ ` ``     | next app / next window                      |
| `⌘ ␣`                 | Spotlight                                   |
| `⌘ M` / `⌘ W` / `⌘ Q` | minimize / close / quit                     |
| `⌃ ⌘ F`               | fullscreen                                  |
| `⌃ ↑` / `⌃ ↓`         | Mission Control / app windows               |
| `⌃ ←` / `⌃ →`         | previous / next desktop                     |
| `⌘ ⇧ 4` / `⌘ ⇧ 5`     | screenshot / capture menu, `⌃` to clipboard |
| `⌘ ⇧ G`               | Finder: go to folder                        |

## Chrome (Vimium)

| Key              | Does                        |
| ---------------- | --------------------------- |
| `f` / `F`        | click a link / in a new tab |
| `j` / `k`        | scroll                      |
| `d` / `u`        | half page                   |
| `gg` / `G`       | top / bottom                |
| `H` / `L`        | back / forward              |
| `/` then `n` `N` | find on page                |
| `o` / `O`        | open URL, history, bookmark |
| `b` / `B`        | search bookmarks            |
| `T`              | search open tabs            |
| `t` / `x` / `X`  | new / close / reopen tab    |
| `J` / `K`        | previous / next tab         |
| `yy`             | copy the URL                |
| `gi`             | focus the first text field  |
| `⌘ ⇧ N`          | incognito window            |
